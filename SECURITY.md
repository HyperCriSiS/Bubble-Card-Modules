# Security Policy

## Supported versions

Security fixes go into the latest version of each module. Older versions do not get separate fixes.

| Version | Supported |
|---|---|
| Latest module version | Yes |
| Older versions | No |

## Reporting a vulnerability

Please report vulnerabilities privately under **Security → Report a vulnerability** in this repository.

Do not post any of the following in a public issue:

- working exploits
- credentials, passwords or tokens
- personal data

## Helpful details

- affected module and its version
- Bubble Card and Home Assistant versions
- browser or companion app
- steps to reproduce with harmless test data
- possible impact

## Handling

A report is first checked for reproducibility and impact. A confirmed vulnerability gets a fix, a regression test, a changelog entry and, where it fits, a GitHub security advisory. Details are published once a fix is available.

Regular bugs and usage questions belong in the public issue tracker.
